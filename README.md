# Minecraft News Bot 🟩

Телеграм-бот, который **автоматически парсит открытые официальные API** и постит
свежие популярные новости по Minecraft в канал `4421879537`, как только его туда добавляют.

## Возможности

- 🟢 **Автопостинг** — при добавлении бота в канал он сразу публикует последние новости,
  а дальше проверяет источники каждые **2 часа** (до 3 новостей за проход).
- 📰 **Только проверенные источники** (открытые API, без ключей):
  - Официальный контент-сервис лаунчера Minecraft от Mojang Studios
    (`launchercontent.mojang.com` — Java и Bedrock новости);
  - Официальная RSS-лента сайта **minecraft.net**.
- 🖼 **Картинки из источника** — если у новости есть изображение, оно прикрепляется
  к посту. Если картинки нет — пост уходит без неё.
- ✍️ **HTML-форматирование** постов: заголовок, описание, ссылка «Читать полностью»,
  источник, дата.
- 🔍 **Кнопка «Проверка» в ЛС бота** — доступна только для **@mellfreezy**.
  По нажатию бот берёт 1 свежую новость из источников и публикует её в канал.
- 🧠 Помнит, что уже публиковал (файл `posted_news.json`), и не постит одно и то же дважды.

## Быстрый старт

1. Получи токен у [@BotFather](https://t.me/BotFather).
2. Впиши его в файл `.env`:

   ```
   BOT_TOKEN=1234567890:AAваш_токен
   ```

3. Установи зависимости и запусти:

   ```bash
   pip install -r requirements.txt
   python main.py
   ```

4. Добавь бота **администратором** в канал (с правом «Публикация сообщений»).
   Бот сам это заметит и начнёт постить новости.

> ⚠️ Канал задаётся в коде: `CHANNEL_ID_RAW = 4421879537` в `main.py`.
> Telegram выдаёт каналам ID вида `-1004421879537` — бот понимает обе формы.

## Файлы

| Файл | Назначение |
|---|---|
| `main.py` | весь код бота (источники, постинг, кнопка «Проверка») |
| `requirements.txt` | зависимости |
| `.env` | **только** токен бота (`BOT_TOKEN`) |
| `posted_news.json` | создаётся при работе: память об опубликованных новостях |

## Важно про безопасность

`.env` добавлен в репозиторий по требованию владельца, но в нём лежит
**плейсхолдер**. Когда вставишь реальный токен — убедись, что репозиторий
приватный, либо держи `.env` только на сервере (и удали его из git),
иначе токен могут украсть. Если токен утёк — сбрось его через @BotFather (`/revoke`).
